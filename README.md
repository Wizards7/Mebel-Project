# Mebel-Project

Онлайн-мағозаи мебел дар Тоҷикистон (Next.js 15, Prisma, Tailwind CSS, TypeScript).

## Хусусиятҳо
- Каталоги мебел бо филтрҳо ва ҷустуҷӯ
- Сабади харид ва сабти фармоиш
- Панели админ барои идоракунии маҳсулот ва фармоишҳо
- Пойгоҳи додаҳо бо Prisma ORM (SQLite / PostgreSQL)

## Оғози кор

1. Насб кардани вобастагиҳо:
```bash
npm install
```

2. Танзими тағйирёбандаҳои муҳит:
Файли `.env` созед ва арзишҳоро мувофиқи `.env.example` танзим кунед.

3. Омодасозии пойгоҳи додаҳо:
```bash
npm run db:push
npm run db:seed
```

4. Оғози сервери таҳия:
```bash
npm run dev
```

Лоиҳа дар [http://localhost:3000](http://localhost:3000) дастрас мешавад.
